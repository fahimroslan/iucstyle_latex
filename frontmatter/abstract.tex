\begin{abstract}
This thesis template provides a complete and structured framework for academic
writing, including front matter, declarations, acknowledgements, chapter
organization, and references. The work emphasizes a modular document
architecture in which content is separated into dedicated files to improve
maintainability, collaboration, and version control. The proposed approach
supports clearer writing workflows, consistent formatting, and scalable project
organization for postgraduate research manuscripts.

\keywords{thesis template, academic writing, document structure}
\end{abstract}
